# 00 — Vision & Principles

## 무엇인가

anamnesis는 **개인 머신에 상주하는 메모리 엔진**이다. 에이전트(Claude Code,
커스텀 에이전트, 워처)들이 클라이언트로 붙어 "일어난 일"을 보내고, "아는
것"을 물어본다. 엔진은 원본을 평생 보존하는 금고와, 그 위에서 추출·연결·회상을
수행하는 기억 공간으로 구성된다.

## 두 개의 세계: 금고와 엔진

```text
vault  (불변)   일어난 일의 원본. append-only. 한 번 쓰이면 영원히 그대로.
memory (파생)   추출된 사실, 링크, 임베딩, 질량. 전부 소모품 —
                언제든 통째로 지우고 금고에서 재구축할 수 있다.
```

이 분리가 모든 설계 결정의 뿌리다:

- 추출 프롬프트·임베딩 모델·스키마가 아무리 바뀌어도 원본은 무사하다.
  개선된 파이프라인을 **과거 전체에 소급 적용**할 수 있다.
- 기억 공간이 오염되거나 망가져도 `rm -rf memory/` 후 재구축하면 된다.
- 백업은 `~/.anamnesis` 디렉토리 복사 하나로 끝난다.

기존 엔진 중 어떤 것도 이 완전한 재구축 가능성을 갖지 못한다 — Mem0는 원본을
버리고, Zep은 원본(Episode)이 파생 그래프와 같은 DB에 묶여 있다.

## 핵심 원칙

### 1. 자연어가 기본 표현이다

각 정보는 타입·온톨로지를 최소화하고 **정규화된 자연어 문장**으로 저장한다.
"사용자 선호" 같은 스키마 열이 아니라 "이노는 다크 모드를 선호한다"라는
문장이다. 구조는 회상에 꼭 필요한 최소만 남긴다: 원소당 시간 하나, 링크
role 7종 (graphiti 어휘 차용, docs/09 §4).

근거: Mem0 논문에서 자연어 사실 저장이 그래프 triplet을 single/multi-hop에서
이겼고, Supermemory는 관계 타입 단 3개로 LongMemEval SOTA를 냈다. 구조가
실제로 이기는 영역은 시간 추론뿐이며, 그건 시간축과 invalidation으로 푼다.

### 2. 객체당 시간은 정확히 하나, 그리고 그것은 사건 시간이다

- 원본: 실제 발생 시각.
- 추출 정보: **내용이 가리키는 시각** (explicit / relative / inherited).
- 파생물(요약 등): 생성 시각.

createdAt/ingestedAt 같은 운영 타임스탬프는 데이터 모델에서 배제한다.
"언제 들었는가"가 아니라 "언제의 일인가"가 기억의 축이다.

### 3. 파괴적 갱신은 없다

모순이 발견되면 기존 사실을 고치거나 지우지 않는다. **invalidation 자체가
자기 시간을 가진 하나의 사건**이고, `INVALIDATES` 링크로 연결된다.
"시점 T의 유효한 사실 집합"은 저장된 상태가 아니라 T를 넣어 계산하는 값이다.
이로써 Zep의 bi-temporal 표현력을 더 적은 개념으로 얻는다.

### 4. 질량과 거리는 저장하지 않고 계산한다

- **거리**: 질의 시점에 의미(임베딩) + 시간 근접 + 그래프 거리 + 엔티티
  일치의 가중 합성으로 계산한다.
- **질량(중요도)**: `mass(T) = f(강화 이력, 감쇠)` — 시간의 결정론적 함수라
  데몬이 tick으로 깎을 필요가 없고, 읽기 시점에 T를 넣어 평가한다.
- **풍화**: 위 결과. 아무도 읽지 않는 동안 "실시간으로 썩을" 필요가 없다 —
  다음에 읽을 때 그만큼 썩어 있으면 결과가 같다.

### 5. 시점 절단이 1급 연산이다

`snapshot(T)` = `time <= T`인 원소·링크만으로 구성된 세계. 백필(과거 데이터를
나중에 넣는 것)을 하면 과거 세계가 풍부해지는데, 이는 버그가 아니라 의도된
동작이다. 원본-파생 분리 덕에 소급이 항상 깔끔하다.

### 6. 사람은 해석하지 않고 매핑한다

원본의 `origin.actor`에는 플랫폼 ID(예: `U098765`)를 그대로 둔다. "U098765는
김철수다"라는 인식은 원본을 덮어쓰는 게 아니라 **별도의 매핑 기억**으로
존재한다. 매핑이 틀렸어도 원본은 무사하다.

### 7. 로컬이 곧 주권이다

서버 없음, Docker 없음, SaaS 없음. npm 설치 한 방, 데이터는 전부
`~/.anamnesis/` 아래 파일. 사용자가 자기 기억을 열어보고, 백업하고, 지울 수
있다. Zep·Mem0·Supermemory가 전부 서버/클라우드 제품인 시장에서 "서버 없는
로컬 상주 엔진"의 빈칸이 우리 자리다.

## 세 계층

```text
원본 기억      금고의 레코드. 불변. 시간축(session + time 정렬)만 가진다.
추출된 주장    원본에서 LLM이 뽑은 자연어 사실. 불변 (틀렸으면 invalidate).
통합된 사실    주장들을 되씹어 만든 상위 사실·요약. 재계산 가능.
```

의미 관계(RELATES_TO)는 추출 계층 이상에서만 존재한다. 원본끼리는
시간축뿐이다.
