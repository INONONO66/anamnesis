# 09 — 우주 모델: 워딩, 층, 질량 역학

> docs/01(데이터 모델)·03(recall)의 mass 설계를 공식 워딩으로 고정하고
> 망각 역학을 형식화한다. 여기 용어가 코드·문서 전반의 표준이다.

## 1. 시간 워딩 — 의미 있는 시간은 하나

| 용어 | 정의 | 취급 |
|---|---|---|
| **사건 시각** (event time) | 그 일이 실제로 행해진 / 참이 된 시각. `time_utc` | 유일한 의미 축. 시퀀스·snapshot 절단·유효성 판정 전부 이 축 |
| **기록 시각** (recorded time) | 엔진에 유입/생성된 시각 | 메타데이터. 복구·감사 전용. 어떤 판정에도 쓰지 않는다 |

- **snapshot(T) = "그 시점의 세계"다.** 3월의 사건이 9월에 늦게 유입돼도
  5월 스냅샷에 나온다. "엔진이 그때 뭘 알았나"가 아니라 "그때 세계가
  어땠나"를 답한다. (Zep의 bi-temporal 이중 축에서 사건 축만 의미 축으로
  남기고 유입 축은 감사 로그로 강등 — 복잡도 절반.)
- 파생물(사실)도 사건 시각을 가진다: "부산으로 이사했다"의 시각은 추출된
  9월이 아니라 이사한 3월이다. 추출 시각은 기록 시각(메타)이다.

## 2. 층 워딩 — 축적 순서 그대로

```text
0층  시간축         엔진 전체를 관통하는 단 하나의 사건 시각 축
1층  흐름(세션 체인)  같은 세션의 에피소드가 사건 시각 순으로 사슬 연결
                    └ remember() 순간 자동 배선. LLM 0. 최초의 구조
                    └ 사슬은 나무다: 되감기 = 분기. 본선은 가지 서열
                      index 0 (읽기 시점 유도, docs/01 유입 의미론)
2층  엔티티          흐름에서 추출된 사람·사물·개념 앵커. 시간을 안 탐
3층  사실(정보)      엔티티들에 대해 성립하는 자연어 서술. 사건 시각 = 참이 된 때
```

층은 계급이 아니라 축적 순서다. 아래층은 위층 없이 성립하지만 역은 아니다.

## 3. 우주 워딩 — 원소의 천체 대응

| 천체 | 원소 | 성질 |
|---|---|---|
| **먼지** | 에피소드 | 시간축 위에 무수히 깔림. 가장 빨리 풍화. 불변 — 소멸하지 않고 노출만 잃는다 |
| **돌덩이** | 엔티티 | 사건 시각 없음, 풍화 없음. 먼지 사이에서 응결된 앵커 |
| **행성** | 사실 | 먼지에서 추출되어 엔티티 궤도를 돎. 천천히 풍화 |
| **항성** | 중요 엔티티 | 중력 중심. 회상 확산(PPR)의 시드 |

천체는 은유가 아니라 저장 구조다 — Neo4j 노드 라벨로 물질화된다:
`(:Element:Episode)` `(:Element:Entity)` `(:Element:Fact)`
`(:Element:Community)`. 엣지를 관계 실타입으로 물질화한 것과 같은 원리고,
허용 (출발, 엣지, 도착) 격자는 docs/01에 잠긴다.

**항성은 지정이 아니라 창발이다.** 엔티티의 중력 = 궤도의 질량 합
(연결된 사실·에피소드의 m(T) 합). 딸린 행성이 많으면 저절로 항성이 되고,
관심사가 바뀌면 자연히 식는다. 수동 승격 없음.

## 4. 링크 role — 7종 확정 (graphiti 어휘 차용)

> [갱신 2026-08-31] 자체 명명(sequence/provenance/about/semantic) 대신
> graphiti 엣지 체계를 차용하고, 개네한테 없는 우리 시그니처 3종을 더한
> 합집합. 저장 시 role 프로퍼티가 아니라 **Neo4j 관계 실타입**(UPPER_SNAKE)
> 으로 물질화 — 타입 기반 순회 필터와 GDS projection이 정석.

| role | 축 | 연결 | 비고 |
|---|---|---|---|
| `NEXT_EPISODE` | 시계열 | 에피소드 → 같은 세션 직후 에피소드 | remember() 자동 배선. PPR이 대화 흐름을 타게 하는 물질화 |
| `MENTIONS` | 의미 | 에피소드/사실 → 엔티티 | PPR 시딩 연료 |
| `RELATES_TO` | 의미 | 원소 ↔ 원소, content에 자연어 관계 문장 | graphiti fact-on-edge 대응. 임베딩 대상 |
| `HAS_MEMBER` | 구조 | 커뮤니티(은하) → 구성원 | dreaming이 생성 (v0.3) |
| `DERIVED_FROM` | 의미 | 가공물 → 근거 원본 | 출처 사슬. graphiti에 없음(개네는 엣지 프로퍼티) — 우리 확장 |
| `INVALIDATES` | 의미×시간 | 무효화 사건 → 사실 | 판정 끝난 무효화. 유일한 "수정" 수단. 우리 시그니처 |
| `CONTRASTS` | 의미 | 미해소 모순의 양쪽 보존 + 사유 문장 | 증거가 쌓이면 dreaming이 INVALIDATES로 승격. 우리 시그니처 |

구조적 의미가 있는 것만 role로 잠그고(위 7), 관계의 다양성은 전부
RELATES_TO의 자연어 content로 흡수한다.

## 5. 망각 역학 — mass(T)

모든 원소는 고유 질량 `m₀`(0~1, 탄생 시 부여, 불변)를 가진다.
읽기 시점 평가 (정본 수식·근거·파라미터는 [docs/10](10-dynamics-math.md)):

```text
m(T)    = m₀ × R(t, S),  t = T − t_last_hit (days)
R(t,S)  = (1 + FACTOR·t/S)^DECAY               ← 멱법칙 (FSRS 곡선, 지수 아님)
히트 시   S′ = S·(1 + a·κ(kind)·(e^{b·(1−R_hit)} − 1)·S^{−c})  ← 포화 간격 효과·회수>재노출
최종 랭킹 = RRF(vector, bm25, ppr) × m(T)^γ     ← 곱셈 가중, 하드 필터 금지
```

- **풍화**: 활성 없이는 멱법칙 감쇠 — 초반에 빨리 잊고 꼬리가 두껍다.
  S_base는 먼지 < 행성 순으로 크고, 엔티티는 풍화하지 않는다(∞).
- **재활성화**: recall 채택 = 히트 → `t_last_hit` 갱신 + S 증가. 강화폭은
  히트 순간의 잔존율이 낮을수록 크다(간격 효과 — massed 재노출은 무력).
  식은 먼지도 히트로 부활.
- **망각 ≠ 삭제**: m(T)→0이어도 원소는 보존된다. 노출 지분만 잃으며,
  정면 지목 질의(압도적 관련도)에는 여전히 응답한다.
  (hermes ADR-102와 동일 결론: temporal 가중은 multiplicative, not filter.)

### 불변성과의 정합

정본은 CREATE-only **히트 원장**(docs/10 카드 2)이고, `(S, t_last_hit,
hits)` 프로퍼티는 원장에서 언제든 재생되는 캐시다. 원소·링크·페이로드와
마찬가지로 히트 원장도 보존 대상이다 — 유실되면 m(T)가 비가역 손실된다.

## 6. 공간 배치 — 임베딩이 곱 좌표다

모든 원소(와 RELATES_TO 링크)의 `embedding` 프로퍼티가 의미 공간에서의
좌표다. Neo4j 벡터 인덱스(HNSW)가 공간 인덱스 역할을 하므로 별도 벡터
DB에 배치를 복제하지 않는다 — **그래프 노드 자체가 공간상의 천체다.**

```text
원소 하나 = 천체 하나
├─ 좌표   embedding (의미 공간 위치 — 비슷한 의미끼리 근접)
├─ 시각   time_utc (시간축 — 공간과 독립인 축)
├─ 질량   m(T)
└─ 연결   links (중력선)
```

recall = 물리 시뮬레이션: 질의가 공간의 한 점에 떨어지고 → HNSW가 근방
천체를 찾고 → 활성화가 중력선을 타고 번지고(PPR — sequence는 대화 흐름,
about은 항성 경유 확산) → 밝기 = 관련도 × m(T). 의미 클러스터는 공간상
뭉치므로 Leiden이 검출하는 커뮤니티 = **은하** (dreaming의 통합 단위).

캐비앗: Neo4j 벡터 인덱스는 ANN 후 시간 절단을 후필터로 거른다(여유분
과추출 패턴). 먼 과거 스냅샷 질의가 잦아 후필터 낭비가 실측되면 그게
Qdrant(필터드 ANN 네이티브) 재검토 트리거다 (docs/08 §4).
